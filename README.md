## О проекте

**Nexora** - мобильное Android-приложение для ведения личных заметок, конспектов и записей о близких, в котором ИИ-ассистент работает не по «общей свалке» данных, а строго внутри **изолированных пространств** («Учёба», «Проекты», «Личное», «Люди» и др.).

### Целевая аудитория
- **Студенты и исследователи**, которые ведут конспекты, фиксируют термины, идеи и планы проектов и хотят быстро находить нужную информацию по смыслу или получать структурированные выжимки без смешивания с личными записями.
- **Пользователи, которым важно помнить детали о близких** - фиксировать обронённые в разговоре пожелания, следить за важными датами и подбирать аргументированные подарки на основе реальных записей.

## Решаемые проблемы и отличия от аналогов

| Проблема повседневных заметок | Подход Nexora |
| :--- | :--- |
| **Заметки копятся и теряются** - через полгода сложно вспомнить, где лежит нужный факт, а обычный поиск ищет только точные совпадения слов. | **Семантический поиск и RAG** по фрагментам (чанкам) заметок с обязательным указанием источников. |
| **Общий чат с ИИ смешивает контексты** - учебные конспекты, рабочие задачи и личные записи попадают в один поток, снижая точность ответов и приватность. | **Строгая изоляция пространств по умолчанию**: ассистент «Учёбы» не видит раздел «Люди», пока пользователь сам не разрешит объединение. |
| **Мелкие факты о людях забываются** - к дню рождения пожелания друга не вспоминаются, а обычный LLM-чат не хранит историю за месяцы. | **Выделенное пространство «Люди»** с быстрой фиксацией фактов за 5 секунд, детектором намёков, историей подарков и списком «избегать». |

> **Отличие от Notion AI, Obsidian и Google Keep:** существующие инструменты либо требуют ручной организации графа и не имеют встроенного трекера отношений с подбором подарков, либо используют единый контекст ИИ без строгой изоляции пространств и проверки на «галлюцинации» (честный отказ при нехватке данных в заметках).

## Ключевые концепции

### 1. Изолированные пространства (Spaces)
Каждое пространство представляет собой независимый контейнер со своими заметками, поисковым индексом и системной инструкцией для ИИ-ассистента:
- **Учёба** - конспекты, определения, планы подготовки; ассистент объясняет материал и собирает сводки.
- **Проекты** - идеи, задачи, архитектурные решения; ассистент собирает статус и ищет упомянутые гипотезы.
- **Люди** - карточки близких; ассистент отслеживает даты, выделяет намёки и подбирает подарки.
- **Пользовательские пространства** - произвольная структура под задачи владельца.

### 2. Пространство «Люди» и подбор подарков
- **Карточка человека:** имя, роль/отношение (друг, брат, преподаватель), важные даты, хронология фактов, история подарков с реакцией и список ограничений («избегать»: аллергии, антипожелания).
- **Запись за 5 секунд и «Ловец намёков»:** ввод одной строкой в стиле мессенджера (*«Паша жаловался, что наушники сломались»*) с автоматической классификацией типа факта (интерес, нужда, намёк, антипожелание).
- **Аргументированный подбор подарков:** генерация 5–7 идей под заданный повод и бюджет с прямой ссылкой на исходную заметку, проверкой на дубликаты из истории подарков и фильтрацией по списку «избегать».

### 3. Интерактивная карта пространств («Звёздное небо»)
Визуальная навигация в виде космического графа: центральное ядро **Nexora** соединено цветовыми рёбрами с узлами пространств (орбитальная раскладка для 1–6 узлов и древовидная иерархия при большем количестве).

## Локальное хранилище Android

При первом запуске Nexora предлагает выбрать папку в системном проводнике Android. На следующих запусках приложение открывает её автоматически. Если доступ потерян, можно выбрать папку повторно.

Каждое пространство получает свою папку прямо внутри выбранной папки. Например, заметки пространства «Работа» лежат в `Nexora-Notes/Работа/`. Для одинаковых названий Nexora добавляет номер, например `Работа (2)`. Символы, недопустимые в именах папок, заменяются или удаляются.

- Каждая заметка хранится отдельным файлом `.md`. В начале файла записаны заголовок и ID пространства.
- `.nexora-space.json` в папке пространства хранит его ID, название и порядок в списке.
- `nexora-layout.json` в выбранной папке содержит версию структуры хранилища.

При первом запуске после обновления Nexora копирует данные из прежнего `nexora.json`, плоской структуры с Markdown-файлами или вложенной папки `Nexora` в актуальную структуру. Исходные файлы сохраняются. Веб-версия хранит данные локально в браузере.

## Технологический стек

### Текущая клиентская сборка
- **Язык и фреймворк:** TypeScript `5.9.2`, React `19.1.1`
- **Сборщик:** Vite `7.1.3`
- **Мобильная платформа:** Capacitor `7.4.3`
- **Стилизация и графика:** Нативный CSS (CSS Custom Properties, Flexbox/Grid, анимации)

### Целевой серверный и ИИ-стек
- **Backend:** Python (FastAPI)
- **Хранение и векторный поиск:** PostgreSQL / SQLite
- **AI / RAG:** Эмбеддинги фрагментов заметок с метаданными пространства, облачное LLM API с возможностью подключения локальной модели (Ollama) для максимальной приватности

## Быстрый старт и сборка

> Подробное пошаговое руководство по сборке с нуля, настройке окружения и сборке APK доступно в файле [BUILD.md](BUILD.md).

### Требования к окружению
- **Node.js** `22.12+` (или `24.x`) и **npm**
- Для сборки под Android: **Android Studio**, **JDK 21** (для Gradle) и **Android SDK Platform 35**

### 1. Запуск веб-версии в режиме разработки

```bash
npm ci
npm run dev
```

После запуска интерфейс будет доступен в браузере по локальному адресу Vite (по умолчанию `http://localhost:5173`).

### 2. Установка на Android из готового APK (для проверки и демонстрации)

1. Скачайте актуальный файл из раздела [**Releases**](https://github.com/yug33n/Nexora/releases) на Android-смартфон (Android 7.0+ / API 24+).
2. Откройте скачанный файл в проводнике или браузере.
3. Нажмите **«Установить»** и запустите **Nexora** с рабочего стола.

### 3. Сборка APK и запуск из исходников

```bash
# Установка зависимостей
npm ci

# Сборка TypeScript/Vite и синхронизация веб-бандла с Android-проектом Capacitor
npm run android:sync
```

Далее выберите удобный способ сборки:

- **Через терминал (быстрая генерация APK без открытия IDE):**
  ```bash
  cd android
  ./gradlew assembleDebug    # Linux / macOS
  # или gradlew.bat assembleDebug на Windows
  ```
  Готовый установочный файл появится по пути:
  `android/app/build/outputs/apk/debug/app-debug.apk`

- **Через Android Studio (для запуска на эмуляторе или по ADB):**
  ```bash
  npm run android:open
  ```
  Дождитесь завершения **Gradle Sync**, выберите устройство или эмулятор и нажмите **Run (`Shift + F10`)**. Для экспорта APK через меню IDE выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

> При любых изменениях в папке `src/` перед повторной сборкой APK обязательно выполните `npm run android:sync`.
