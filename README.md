# Nexora

Приложение для личных записей: конспекты, идеи и планы живут в изолированных
пространствах — «Учёба», «Проекты», «Личное». Записи одного пространства не
перемешиваются с другими.

## Для кого

Студенты и все, кто ведёт конспекты, идеи и планы и хочет быстро находить нужное.

## Статус

Проект в начале разработки: ведётся каркас интерфейса.

Планируется:

- текстовый поиск по заметкам выбранного пространства;
- карта пространств: узлы с рёбрами от центра Nexora;
- раздел «Люди»: факты о близких, важные даты, идеи подарков.

## Технологии

React, TypeScript, Vite. Сборка под Android через Capacitor — планируется.

## Запуск

```sh
npm install
npm run dev
```
